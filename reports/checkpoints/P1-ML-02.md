# P1-ML-02 — Baseline ML có giới hạn tài nguyên

Kết luận: `RUNTIME_PASS`  
Ngày: 2026-09-23

## Bài toán được chạy là gì?

Baseline ước lượng `HasClaim` đã quan sát cho aggregate risk observation, dùng
`Gender`, `DrivAge`, `VehYear`, `VehModel`, `VehGroup`, `Area`, `StateAb`.
Không có claim field, total, ratio, technical identity hoặc pricing/exposure
field đi vào estimator.

## Dataset và preprocessing

| Hạng mục | Kết quả |
|---|---:|
| Population deterministic | 100,004 rows / 100,000 hash groups |
| Train / validation / test | 60,002 / 20,002 / 20,000 |
| Positive rate | 18.374% / 18.398% / 18.845% |
| Split | `StratifiedGroupKFold(5)`, seed 20260923 |
| Hash qua split boundary | 0 |
| Transform train lớn | 60,000 × 3,528 sparse columns |
| Non-zero values | 420,000; density 0.1984% |

`SimpleImputer(most_frequent)` và `OneHotEncoder(handle_unknown="ignore",
dtype=float32)` chỉ fit trong Pipeline trên training. OHE giữ sparse output;
unknown category khi inference không làm crash pipeline.

## Progressive scale validation

| Train rows | OHE columns | Train time | Validation ROC-AUC | PR-AUC |
|---:|---:|---:|---:|---:|
| 4,000 | 1,706 | 0.210 s | 0.75695 | 0.41794 |
| 23,999 | 2,935 | 0.683 s | 0.79440 | 0.48472 |
| 60,000 | 3,528 | 1.552 s | 0.80208 | 0.49994 |

Scale tăng cho chất lượng ranking tăng mà không tăng memory tới mức lần trước.
Timing extraction/split là 182.505 s; phần model fit rất ngắn vì matrix sparse.

## Baseline và trivial reference

`majority_dummy` luôn dự đoán no-claim: ROC-AUC 0.5, PR-AUC 0.18398, precision/
recall/F1 đều 0 ở threshold 0.5. Accuracy 81.60% chỉ phản ánh class imbalance.

Baseline là `SGDClassifier(loss="log_loss")`: linear classifier tối ưu logistic
style loss bằng stochastic gradient, scalable hơn solver LogisticRegression
`saga` trong local budget; nó không được mô tả là hoàn toàn giống mọi
LogisticRegression solver.

Validation baseline tại threshold 0.5: ROC-AUC **0.80208**, PR-AUC **0.49994**,
precision **0.68178**, recall **0.20027**, F1 **0.30960**; confusion matrix là
`[[15978,344],[2943,737]]`.

Threshold 0.5 chỉ là threshold mặc định để báo metric, không phải production
decision threshold đã tối ưu.

## Kết luận

`RUNTIME_PASS`: baseline train/evaluate thật, preprocessing chỉ học từ train,
split không leakage và resource có giới hạn rõ ràng. Không yêu cầu ROC-AUC cụ
thể để pass.
