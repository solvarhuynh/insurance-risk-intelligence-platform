# P1-ML-05 — Batch scoring vào SQL Server

Kết luận: `RUNTIME_PASS`  
Ngày: 2026-09-23

## Scoring population trung thực là gì?

Scorer chỉ chấm `bounded_held_out_test`: 20,000 test rows của population ML
deterministic. Đây là **out-of-sample batch inference demonstration**, không
phải future customer prediction.

## Prediction lưu ở đâu?

`dwh.RiskObservationPrediction` có grain một source technical identity +
model + scoring population. Các field chính là `SourceFile`, `SourceRowNumber`,
`SourceRecordHash`, `ModelVersion`, `ScoreProbability`, `ThresholdValue`,
`PredictedHasClaim`, `ScoringRunId`, `ScoredAtUtc`.

Không có `Fact_Customer_Risk_Prediction`; source không chứng minh customer.

## Luồng scoring

```text
claim_risk_model_v001.joblib
       + bounded held-out test features từ DWH
       ↓ predict_proba
#PredictionLoad (temp table, text decimal an toàn cho ODBC)
       ↓ một MERGE SQL Server
dwh.RiskObservationPrediction
```

Temp table chỉ tồn tại trong connection. `MERGE` tránh 20,000 MERGE round-trip
riêng lẻ và conversion decimal xảy ra trong SQL Server có kiểm soát.

## Idempotency hoạt động thế nào?

Unique key là `(SourceFile, SourceRowNumber, ScoringPopulation, ModelVersion)`.
Rerun cùng semantics dùng `MERGE`: update row cũ và ghi run ID mới, không insert
duplicate. Sau rerun, SQL có 20,000 prediction rows, 0 duplicate source identity
và 1 distinct stored `ScoringRunId` (run mới nhất).
