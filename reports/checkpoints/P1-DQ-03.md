# P1-DQ-03 — Pipeline quality gate

Ngày: 2026-09-22

Kết quả: PASS

## Cơ chế

`dq.sp_RunQualityGate` ghi từng rule vào `dq.QualityCheckLog`, ghi audit vào `meta.PipelineAudit`, rồi `THROW` nếu có bất kỳ hard rule FAIL. Pipeline tương lai phải gọi gate sau load; SQL exception dừng bước kế tiếp.

## Bằng chứng controlled failure

Gọi `EXEC dq.sp_RunQualityGate @RunLabel=N'controlled-invalid-test', @InjectControlledFailure=1` tạo only-in-memory hard result `CONTROLLED_INVALID_INPUT` observed `1`, expected `0`, ghi log `FAIL`, rồi trả SQL error 51040 và exit code 1 như mong đợi. Không insert/update/delete raw, staging hay fact; count sau test vẫn staging = fact = 1,965,355.

Lần chạy production kế tiếp PASS toàn bộ hard rules, chứng minh valid production data vẫn đi qua gate.
