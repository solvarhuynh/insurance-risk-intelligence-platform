## Artifact là gì?

Artifact là gói đã serialize gồm cả train-only preprocessing và estimator, để
process khác load/score mà không phụ thuộc Python process đã train.

| File | Vai trò |
|---|---|
| `ml/artifacts/claim_risk_model_v001.joblib` | Pipeline sparse preprocessing + `SGDClassifier` |
| `ml/artifacts/claim_risk_model_v001.metadata.json` | version, target, feature, split, metrics, dependency, resource strategy, Git state, limitation |

Artifact không được commit do binary output reproducible bị `.gitignore` loại
trừ; metadata vẫn nằm cạnh artifact local để trace runtime.

## Final model được chọn và train thế nào?

`claim_risk_model_v001` là `SGDClassifier(loss="log_loss")`. Selection dùng
validation AP rồi ROC-AUC, sau đó ưu tiên logistic-loss linear khi hòa. Final
fit dùng deterministic 60,000-row group-complete cap từ train+validation;
held-out test 20,000 rows không dùng trong fit.

## Fresh-process reload test

Một Python process mới load artifact, extract deterministic bounded population,
lấy 100 test row theo thứ tự hash/file/row và score thành công. Kết quả: 100
probability, không missing; range `0.0000750320` đến `0.7419331670`. Probability
trùng tuyệt đối với pipeline còn trong memory trên cùng 100 row.
